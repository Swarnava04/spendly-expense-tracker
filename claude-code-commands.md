# Claude Code Terminal Commands

A reference list of commonly used Claude Code slash commands, compiled from a Claude Code session on 2026-09-12.

## Built-in Commands

| Command | Purpose |
|---|---|
| `/help` | Get help using Claude Code |
| `/clear` | Clear conversation context |
| `/compact` | Summarize/compact context |
| `/resume` | Resume a previous session |
| `/config` | Change model, theme, dictation language, settings |
| `/model` | Switch active model |
| `/permissions` | View/edit tool permission rules |
| `/usage-credits` | Check usage/credit balance |
| `/voice` | Toggle voice dictation |
| `/fast` | Toggle fast mode (Opus, faster output) |

## Skills (invoked as slash commands)

| Command | Purpose |
|---|---|
| `/code-review` | Review diff/PR for bugs and cleanup (supports `ultra` for a deep multi-agent cloud review) |
| `/security-review` | Security-focused review of pending changes |
| `/simplify` | Review and apply simplification/efficiency fixes |
| `/init` | Generate a CLAUDE.md documenting the codebase |
| `/run` | Launch/drive the project's app to verify a change |
| `/loop` | Run a prompt/command repeatedly on an interval |
| `/schedule` | Create/manage cron-based scheduled cloud agents |
| `/update-config` | Configure settings.json (permissions, hooks, env vars) |
| `/keybindings-help` | Customize keyboard shortcuts |
| `/fewer-permission-prompts` | Auto-allowlist common safe commands |
| `/claude-api` | Reference for building with the Claude/Anthropic API |
| `/claude-in-chrome` | Automate Chrome browser interactions |
| `/design` | Create a visual design canvas (mockups, UI, posters) |
| `/dataviz` | Guidance/best practices before building charts |
| `/artifact-design` | Design guidance for Artifacts |
| `/artifact-diagramming` | Diagramming guidance for Artifacts |
| `/artifact-capabilities` | Runtime capabilities available to Artifacts |

## Most Commonly Used Day-to-Day

- `/resume`
- `/clear`
- `/compact`
- `/code-review`
- `/init`
- `/model` / `/config`

*Note: available skills/commands vary by environment and project configuration. This list reflects what was available in this session.*
